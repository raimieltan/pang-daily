# Wheel models

Placeholder low-poly wheel + tire sets for the wheel parts in `src/game-core/wheels/catalog.ts`.
They are generated by `node scripts/build-wheel-models.mjs`, so edit the script, not the files.
The contract is in `docs/VEHICLE_ASSETS.md` §7: right-hand wheel, outboard at +x in car space, and
materials `tire`, `rim`, `rim_dark` and `chrome`.
