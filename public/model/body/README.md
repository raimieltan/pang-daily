# Body part models

Placeholder low-poly body parts for the parts in `src/game-core/exterior/catalog.ts`. They are
generated by `node scripts/build-body-part-models.mjs`, so edit the script, not the files. The
contract is in `docs/VEHICLE_ASSETS.md` §8: car axes, origin at the socket, materials `panel`
(takes the finish) and `hardware`.
